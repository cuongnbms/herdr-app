# herdr-app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS Tauri v2 app that lists herdr Sessions/Workspaces of local and SSH-reachable Machines in a sidebar and shows each Pane through a Terminal lens (real `herdr terminal attach`) or a Chat lens (Claude Code / pi Transcripts).

**Architecture:** A Rust core owns all I/O: JSON-lines RPC on herdr Unix sockets, one subscription per running Session, PTY processes for terminal attach, and a `Transport` that turns every command into either a local argv or an `ssh -S <ctl> …` argv (remote sockets are forwarded to local Unix sockets). React + xterm.js is a pure view fed by Tauri events (sidebar) and Tauri Channels (terminal bytes, chat items).

**Tech Stack:** Tauri 2.x (stable, not 3.0 alpha), Rust 1.95 edition 2021, tokio, serde/serde_json, async-trait, portable-pty 0.9, tracing; React 19, TypeScript, Vite, pnpm, zustand 5, @xterm/xterm 6 + addon-fit + addon-webgl, @tanstack/react-virtual, react-markdown, Vitest + jsdom + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-10-02-herdr-app-design.md` (read its "Refinements made while planning" section: it overrides earlier sections where they differ). Glossary: `CONTEXT.md`.

## Global Constraints

- macOS only. Remote Machines are Linux or macOS with a POSIX-compatible login shell (bash/zsh/sh).
- Required herdr protocol: `pub const REQUIRED_PROTOCOL: u32 = 22;` in `src-tauri/src/herdr/mod.rs`. Any other value → error code `incompatible`.
- Errors: one type, `AppError { code: String, message: String }` in `src-tauri/src/error.rs`, `Display` = `"{code}: {message}"`, serialized to the UI as `{ "code", "message" }`. Allowed codes: `herdr_error`, `timeout`, `io`, `protocol`, `ssh_auth`, `ssh_forward_denied`, `herdr_not_found`, `incompatible`, `attach_held`, `not_found`, `invalid`. herdr error responses map to `herdr_error` with herdr's message. `std::io::Error` maps to `io`.
- IPC JSON is snake_case everywhere; TypeScript types in `src/lib/types.ts` mirror the Rust structs field-for-field.
- A Pane is addressed by `PaneRef { machine_id, session, pane_id }`; its string key is `` `${machine_id}/${session}/${pane_id}` `` (TS helper `paneKey(ref)` in `src/lib/types.ts`). A Terminal attach key is `AttachKey { machine_id, session, terminal_id }`.
- The local Machine has `id = "local"`; remote Machine ids are lowercase `[a-z0-9-]`, at most 16 chars, derived from the label (`machines::slug`).
- herdr argv is always built by `transport::herdr_argv(info, session, args)`: `[info.herdr, "--session", session, ...args]`, except the session named `default` gets no `--session` flag.
- Every string that crosses into a remote shell goes through `transport::sh_quote` (POSIX single quotes; `'` becomes `'\''`).
- Unix sockets created by the app (ssh control sockets, forwarded herdr sockets) live in `/tmp/herdr-app-<uid>/` (mode 0700), from `transport::runtime_dir()`. File names: `<machine_id>.ctl`, `<machine_id>-<8 hex of FNV-1a(session)>.sock`. (macOS caps socket paths at 104 bytes.)
- Timings: RPC 10 s; `exec` 30 s; session start wait 10 s polling every 200 ms; snapshot refetch debounce 150 ms; sidebar emit throttle 100 ms per Machine; idle detach 15 s; reconnect backoff 1, 2, 4, 8, 16, 32, 60, 60… s.
- Terminal flow control: read chunks ≤ 64 KiB; pause reading above 1 MiB unacknowledged, resume below 512 KiB; pastes split into 16 KiB writes.
- Status urgency (highest first): `blocked` > `working` > `done` > `idle` > `unknown`. Parents show the most urgent child (`AgentStatus::rollup`).
- Tauri event names: `sidebar://machine` (payload `MachineView`), `pane://status` (payload `PaneStatusEvent`). Nothing else uses events; streams use Channels.
- Logging only via `tracing` (no `println!`); log files under `<app_log_dir>/`, daily rotation, 5 files.
- Integration tests that need a real herdr are `#[ignore]` and use sessions named `herdrapp-test-<suffix>`, always stopped and deleted at the end (`herdr --session X server stop`, `herdr session delete X`). Run with `cargo test -- --ignored --test-threads=1`.
- Commits: Conventional Commits (`feat:`, `fix:`, `test:`, `chore:`, `docs:`), one per task minimum.
- Credit upstream in `THIRD_PARTY_NOTICES.md` (already present) for transcript code adapted from herdr-web-ui.

## Review Focus

1. Paths with spaces or quotes (cwd, socket, transcript path) on a remote Machine must survive `ssh` quoting → Task 4 `sh_quote` tests and Task 12 `ssh_wrap` test with spaces and `'`.
2. A long session name or Machine label must never produce a socket path over 104 bytes → Task 4 `socket_name_is_short` test.
3. herdr restarting or a Session stopping while watched must surface as a Session error and a retry, not a hang or crash → Task 6 `watcher_reports_closed_when_socket_closes` test.
4. Transcript lines that are partial, invalid UTF-8, or not JSON must be skipped without losing later lines → Task 15 `skips_garbage_lines` test.
5. A flood of terminal output with a UI that stops acking must stop PTY reads, not grow memory → Task 9 `reader_pauses_without_acks` test.

```rust
//! Minimal in-process herdr socket for tests.
use super::types::EventFrame;
use serde_json::{json, Value};
use std::{path::PathBuf, sync::{Arc, Mutex}};
use tokio::{io::{AsyncBufReadExt, AsyncWriteExt, BufReader}, net::UnixListener, sync::broadcast};

pub type Handler = Arc<dyn Fn(&str, &Value) -> Result<Value, (String, String)> + Send + Sync>;

pub struct FakeHerdr {
    pub path: PathBuf,
    _dir: tempfile::TempDir,
    events: broadcast::Sender<Option<EventFrame>>,
    pub calls: Arc<Mutex<Vec<(String, Value)>>>,
}

impl FakeHerdr {
    pub fn start(handler: Handler) -> FakeHerdr {
        let dir = tempfile::Builder::new().prefix("hf").tempdir_in("/tmp").unwrap();
        let path = dir.path().join("h.sock");
        let listener = UnixListener::bind(&path).unwrap();
        let (events, _) = broadcast::channel(256);
        let calls = Arc::new(Mutex::new(Vec::new()));
        let (ev, c) = (events.clone(), calls.clone());
        tokio::spawn(async move {
            while let Ok((stream, _)) = listener.accept().await {
                let (handler, ev, c) = (handler.clone(), ev.clone(), c.clone());
                tokio::spawn(async move {
                    let (r, mut w) = stream.into_split();
                    let mut lines = BufReader::new(r).lines();
                    while let Ok(Some(line)) = lines.next_line().await {
                        let req: Value = serde_json::from_str(&line).unwrap();
                        let (id, method) = (req["id"].clone(), req["method"].as_str().unwrap().to_string());
                        c.lock().unwrap().push((method.clone(), req["params"].clone()));
                        if method == "events.subscribe" {
                            let mut rx = ev.subscribe();
                            let started = json!({"id": id, "result": {"type": "subscription_started"}});
                            w.write_all(format!("{started}\n").as_bytes()).await.unwrap();
                            while let Ok(item) = rx.recv().await {
                                match item {
                                    Some(e) => { let f = json!({"event": e.event, "data": e.data}); if w.write_all(format!("{f}\n").as_bytes()).await.is_err() { return; } }
                                    None => return, // close all subscriptions
                                }
                            }
                            return;
                        }
                        let frame = match handler(&method, &req["params"]) {
                            Ok(result) => json!({"id": id, "result": result}),
                            Err((code, message)) => json!({"id": id, "error": {"code": code, "message": message}}),
                        };
                        w.write_all(format!("{frame}\n").as_bytes()).await.unwrap();
                    }
                });
            }
        });
        FakeHerdr { path, _dir: dir, events, calls }
    }
    pub fn emit(&self, event: &str, data: Value) { let _ = self.events.send(Some(EventFrame { event: event.into(), data })); }
    pub fn close_subscriptions(&self) { let _ = self.events.send(None); }
    pub fn calls_of(&self, method: &str) -> usize { self.calls.lock().unwrap().iter().filter(|(m, _)| m == method).count() }
}
```

Only `type == "message"` entries whose `display` (entry or message) is not `false` produce items: role `user` → `User` from `text` blocks (or string content); role `assistant` → `text` → `AssistantText`, `thinking` (field `thinking`) → `Thinking`, `toolCall` → `ToolCall` (name from `toolName` or `name`, id from `toolCallId`, `id` or `callId`, input from `toolInput`, `input` or `arguments`); role `toolResult` → `ToolResult` (call id from message `toolCallId`/`callId`, output = joined `text` blocks, `is_error` from `isError`). Branch size over 64 MiB (sum of line lengths) → emit `Reset(vec![System { text: "Conversation too large to show; use the Terminal lens." }])` and stop parsing.
